# Current state — 2026-09-22

## Product and architecture

**Verified in source:** A Next.js 16/React 19 weekly studio scheduler has authenticated workspace selection/creation, manager setup for studio hours, rooms, teachers, classes, sessions, rosters and student relationships, reviewed CSV intake, typed policy authoring and review, readiness/certification, schedule generation, candidate scoring/review, manual edits, locks, recovery, version history and print/CSV export. Routes and components are under `app/`, `components/`; core compiler, readiness, commands and quality logic are under `lib/`. Supabase Auth and tenant-scoped SQL migrations back the UI; `solver/dwde_solver` uses Python OR-Tools CP-SAT. `.github/workflows/ci.yml` and `solver-ci.yml` define quality, disposable database, authenticated browser, parity and solver checks.

**Verified authority:** RulebookVersion holds reviewed policy, PlanningDatasetVersion holds mutable planning facts, ConstraintModelVersion holds deterministic compiled meaning, and ScheduleVersion holds adopted placements. Server commands and SQL gates bind tenant/current membership and version context; historical versions remain. Relevant sources: `lib/domain.ts`, `lib/constraint-compiler-v3.ts`, `lib/constraint-engine-v2.ts`, `lib/server-studio-state.ts`, `lib/schedule-readiness.ts`, `app/api/solver/feasibility/route.ts`, `supabase/migrations/`, `solver/dwde_solver/service.py`. The current scheme is bounded weekly scheduling in one timezone, daytime on a 15-minute grid; it is not a general calendar or studio CRM.

**Verified code surfaces, not external acceptance:** `components/app-shell.tsx` exposes the manager journey; `app/api/solver/{feasibility,candidates,adopt}` and schedule command routes implement the server path. `lib/schedule-quality.ts` and migration `20260912100000_cand01_persisted_solver_candidates_v68.sql` back quality and candidate persistence. `supabase/migrations/20260911170000_import01_reviewed_csv_v67.sql` backs reviewed imports. AI/Copilot and legacy scenarios still have code/UI surfaces; accepted `DEC-107` confines AI to optional proposal/explanation and keeps it outside legality. These surfaces are not a release requirement.
