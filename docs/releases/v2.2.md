# DWDE Studio Scheduler V2.2

Release marker for the V2.2 enforcement-mapping rollout.

Runtime code is the V2.2 merge from PR #6. This marker intentionally changes no application behavior or studio data.

V2.2 establishes three independently versioned truths:

- RulebookVersion: human-reviewed scheduling policy.
- EnforcementVersion: explicitly approved deterministic machine mappings.
- ScheduleVersion: assignments linked to the RulebookVersion and EnforcementVersion used to validate them.

At release time, the six seeded business-rule mappings remain PROPOSED and non-enforcing pending explicit human review.
